## 📌 Project Overview

This is a **SQL learning project** developed based on **an online tutorial** to practice and strengthen my SQL skills.

Using a COVID-19 dataset, I analyzed the spread and impact of COVID-19 across different countries, focusing on key indicators such as **total cases, death rates, infection rates, and vaccination coverage**.

Throughout the project, I practiced and applied various SQL techniques, including:

- `JOINs`
- `CTEs`
- `Window Functions`
- `Aggregate Functions`
- Data filtering and sorting
- Data type conversion and calculations

The analysis aims to transform raw COVID-19 data into meaningful metrics and insights while strengthening my understanding of SQL for data analysis.
